# Three-minute demo rehearsal

Start with a fresh isolated demo database. Retain old databases instead of deleting them. The dashboard must show the actual inference mode. State explicitly: all vendor actions and credits are synthetic.

## 0:00–0:30 — Problem and source

“InfraClaim connects an infrastructure incident to contractual obligations, builds a cited claim and verifies the commercial outcome.” Show the ingested three-page ThermaCore PDF, Section 7.4/page 2, $10,000 per eligible hour and $50,000 cap.

## 0:30–1:30 — Hero workflow

Click **Run $40K simulated workflow**. Show the persisted timeline, evidence graph, reasoning citations and policy checks. The worker submits a simulated claim, receives a maintenance dispute, runs a cited counter-investigation, accepts the simulated vendor response and waits for the posted memo. Acceptance alone must not increase recovery.

## 1:30–2:10 — Verify outcome

Show the matched memo, parties/currency/amount checks and **RECOVERY VERIFIED: $40,000**, labelled as a simulated credit ledger. Reload the page to show persistence. Explain that deterministic code calculates the entitlement; the model interprets evidence.

## 2:10–2:40 — Safe exception

Click **Run ambiguous case**. Show the exception queue, overlap/conflict evidence and blocked actions. Return to the saved hero case to prove the exception did not replace it.

## 2:40–3:00 — Honest evaluation

Show the separately saved report for the demonstrated mode. Mock benchmarks validate orchestration and guardrails. Discuss real-model accuracy only after the live report contains successful actual provider calls for all scenarios. Describe the $40,000 as simulated, never as money recovered from a real vendor.

## Recovery from a demo problem

- API offline: verify local processes or container health; saved cases remain in the database.
- Missing key/provider error/refusal/invalid JSON: explain the human-review hold; do not switch silently to mock.
- Unexpected live routing: inspect report failures, correct prompts/validation and rerun with a new report filename. Keep earlier results.
- Already completed hero: select the saved case for review, or use a new isolated database for a fresh rehearsal.
- Unknown PDF: supported-template/manual-review limitation; never invent contract terms.
